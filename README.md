# ppls-voice-recognition-speaker
High-performance speaker recognition pipeline. Processes VoxCeleb and Common Voice datasets using advanced PyTorch models to accurately identify celebrities, athletes, and crowdsourced voices via precise, real-time voiceprint embeddings.

## Getting Started
1. `pip install -r requirements.txt`
2. Run `python src/ingest.py` to acquire raw data.
3. Use `src/inference.py` to compare voiceprints.
